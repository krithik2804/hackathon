Module 04 · safety & consent

Moderation & Privacy Shield

A garment-coverage classifier built on the pose skeleton: it never classifies bodies or people, only whether clothing covers the anatomical regions that must be covered. Runs on the same frames the tracker already holds in RAM, so no second stream, no upload, no storage.

Why “Calibrate to my outfit” mattersSkin-tone thresholds alone mislabel tank tops, dark lighting and deep skin tones. So the shield first records your baseline coverage profile during setup (your actual outfit, your skin tone, your room lighting) and then alarms only when coverage drops relative to that baseline or absolute coverage collapses. That single change removes most false positives and works across skin tones.

Architecture

1Frame is already in canvas memory for pose tracking — the shield reuses it, so cost is one pixel pass, not a second model.
233 landmarks → three anatomical polygons (upper torso, pelvis + thighs, control limb) via Path2D hit-testing on subsampled pixels.
3Pixels classified as skin by an RGB + HSV rule set (Peeradee et al.) → per-region skin fraction, hue variance and luminance.
4Verdict = f(absolute coverage, coverage drop vs calibrated baseline, pose confidence). Median-of-N temporal vote suppresses single-frame flicker.
5On BLOCKED: UI blur, scoring halted, history write refused, no frame ever leaves RAM. Explicitly not a body-shaming or identity system.

Known limits — read before demoing

Height accuracy claims›
Uncalibrated anatomical-prior mode is typically ±4–8 cm because biacromial width varies between people. A4-reference mode is ±1–2 cm. One-time calibration on a phone typically gives ±2–4 cm. The UI always states which mode produced the number — never silently overclaims.
What the modesty screen is not›
It is not a nudity classifier in the ML sense and it does not identify anyone. It measures pixel coverage of anatomical polygons using a colour rule. It can miss thin fabrics and it can flag a bare-torso stretch routine — which is why it is a safety gate that blocks saving, not evidence of wrongdoing.
Rep counting edge cases›
Occluded limbs (side plank, burpee bottom-out), very dark clothing against dark floors, and camera shake degrade landmark quality. The engine degrades by rejecting reps and exposing a rejection counter rather than guessing — visible score drops are intentional.
Why HTTPS is mandatory›
Browsers only expose getUserMedia in secure contexts. Opening this file from file:// or plain http:// on a phone will be blocked by the browser, not by the app. Use GitHub Pages, or python3 -m http.server + localhost on a laptop.
